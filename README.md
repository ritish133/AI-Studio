# AI Studio

AI Studio is your all-in-one hub for powerful, production-ready AI tools—built to streamline productivity, creativity, and personal growth. Serving as the home page for a suite of advanced AI applications, AI Studio offers a seamless experience for discovering and accessing a variety of smart utilities through a unified, elegant interface.

## Features

- **AI Tool Hub:** Browse, preview, and launch a range of AI-powered tools from a single dashboard.
- **Unified Modern UI:** Built using React and Tailwind CSS for a fast, responsive, and visually appealing user experience.
- **One-Click Access:** Instantly launch tools such as MockMate AI (mock interviews), CreatorAI (content generation), Formify (AI form builder), Travelocity (AI travel planner), Imagine AI (AI image generator), and more.
- **Secure Payments:** Integrated with Stripe for managing subscriptions and unlocking premium features across all tools.
- **Consistent User Experience:** Enjoy seamless transitions and unified themes across all AI Studio tools.

## Included AI Tools

- [**MockMate AI**](https://github.com/ritish133/AI-Mock-Interview) &mdash; AI-powered mock interview platform with video, audio, and analytics.
- [**CreatorAI**](https://github.com/ritish133/CreatorAI) &mdash; Versatile content generation using Gemini AI with history and copy features.
- [**Formify**](https://github.com/ritish133/Formify) &mdash; Smart AI form builder with easy customization and response management.
- [**Travelocity**](https://github.com/ritish133/AITravelPlanner) &mdash; AI-powered travel planner and itinerary generator with Google Maps integration.
- [**Imagine AI**](https://github.com/sukantabhun/Imagine-AI-MERN) &mdash; Advanced AI image generator for creating stunning visuals from text prompts.
- *And more, all accessible from within AI Studio.*

## Tech Stack

- **Frontend:** React
- **Styling:** Tailwind CSS
- **Payments:** Stripe

## Getting Started

### Prerequisites

- Node.js ≥ 16.x
- Yarn or npm

### Installation

```bash
git clone https://github.com/ritish133/AI-Studio.git
cd AI-Studio
npm install
# or
yarn install
```

### Configuration

1. Create a `.env.local` file in the root directory.
2. Add your Stripe and any other required environment variables for the integrated tools.
3. Update any relevant URLs or configuration in the project settings.

### Running the App

```bash
npm run dev
# or
yarn dev
```
Visit `http://localhost:3000` in your browser.
